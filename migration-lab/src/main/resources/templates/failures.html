Advanced failure lab

Four failures that no retry fixes, each run twice: once with the design that looks reasonable, once with the design that survives. The dangerous parts run on their own PostgreSQL and their own Kafka broker, never on the services' data. Nothing here is simulated in the browser: every number is what a stage read back.

Start the lab's infrastructure with docker compose --profile failure-lab up -d (about 0.5 GB: failure-postgres and kafka-secure).
